# 📝 To-Do List WebApp

A minimal and intuitive To-Do List web application built with **Python** and **Flask**, implementing full CRUD (Create, Read, Update, Delete) functionality.

---

## 📌 Features

- ✅ Add new tasks
- 📋 View all tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- 🕒 Real-time updates via page refresh
- 🎨 Clean and responsive UI using HTML + CSS

---

## 🧰 Tech Stack

| Layer        | Technology       |
|--------------|------------------|
| Backend      | Python, Flask    |
| Frontend     | HTML, CSS        |
| Template Eng.| Jinja2           |
| Database     | SQLite (default via Flask) |
| Deployment   | Vercel           |
